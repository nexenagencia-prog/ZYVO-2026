# ZYVO Pricing Page Design

## Goal
Create a new `/planos` page that reproduces the supplied pricing reference inside the existing ZYVO app without changing the current Home layout, colors, hero structure, or unrelated UI.

## Experience
- The existing top navigation item `Planos e Preços` opens `/planos`.
- The page uses the same clean, refined ZYVO visual language and scales to the real desktop viewport.
- Three pricing cards: Grátis, Pro, Business.
- Pro is visually highlighted as the recommended/current selection.
- Monthly/Annual segmented control with `-20%` badge; annual prices update to the discounted monthly equivalent.
- Responsive behavior keeps cards readable on narrower screens.

## Copy
Use the exact copy from the supplied reference for headings, plan names, descriptions, feature lists, CTAs, helper text, and prices.

## Constraints
- Do not create a mockup or image asset.
- Do not alter the Home hero, current Home card layout, or existing color system.
- Add only the new pricing route and the navigation link needed to reach it.
