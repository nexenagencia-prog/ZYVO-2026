# ZYVO Space Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fully interactive, local-first meeting workspace at `/space` without changing the approved design of existing ZYVO pages.

**Architecture:** A route-local React client composes the workspace and browser capabilities, while a pure model module owns data transformations. CSS is scoped to `.space-page`; the shared sidebar only gains one route entry.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript, lucide-react, CSS, MediaDevices, Web Share/Clipboard, localStorage, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-11-space-design.md`

## Global Constraints

- Work only on branch `dev`; do not deploy or modify `main`.
- Preserve every existing page's approved visual design.
- Scope new visual rules beneath `.space-page`.
- Stop media tracks during toggle-off and component cleanup.
- Persist user-created Space data locally and tolerate unavailable storage.
